\# ParkQR – QR Code Based Smart Parking Management System



\## About the Project



ParkQR is a QR code-based smart parking management system designed to simplify and digitize the parking process. It provides a centralized platform for managing parking requests, vehicle entry, exit verification, slot allocation, and fare calculation.



\## Problem Statement



Traditional parking management systems often involve manual processes for vehicle registration, parking allocation, entry verification, and payment calculation. These processes can cause delays and inefficient parking management.



\## Proposed Solution



ParkQR provides a digital solution using unique QR codes. Customers can request parking, receive a QR code, and use the same QR code for vehicle entry and exit verification.



\## Key Features



\- Customer Registration and Login

\- Staff and Admin Dashboard

\- Parking Request Management

\- Unique QR Code Generation

\- Staff-Based Parking Approval

\- Parking Slot Allocation

\- QR-Based Vehicle Entry

\- QR-Based Vehicle Exit

\- Automatic Parking Duration Calculation

\- Fare Calculation

\- Digital Parking Receipts



\## Technology Stack



\- Frontend: HTML, CSS, JavaScript

\- Backend: Python

\- Database: SQLite

\- Communication: REST APIs

\- QR Generation: JavaScript QR Code Library



\## System Workflow



1\. Customer registers or logs in.

2\. Customer submits a parking request.

3\. System generates a unique QR code.

4\. Staff approves the parking request.

5\. A parking slot is allocated.

6\. Staff scans the QR code during vehicle entry.

7\. Entry timestamp is recorded.

8\. The same QR code is scanned during exit.

9\. Parking duration and fare are calculated.

10\. Payment processing and receipt generation are completed.



\## Installation



\### Prerequisites

\- Python 3.x

\- Git

\- Web Browser



\### Setup



1\. Clone the repository:



&#x20;  `git clone https://github.com/anushkaaaa02/-ParkQR.git`



2\. Open the project directory.



3\. Install dependencies:



&#x20;  `pip install -r requirements.txt`



4\. Start the backend:



&#x20;  `python server.py`



5\. Open the application in your browser using the local server address.
